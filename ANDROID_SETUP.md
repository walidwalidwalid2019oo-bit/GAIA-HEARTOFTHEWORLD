# Run GAIA on Android with Pydroid 3

This first build uses only Python's standard library. No pip packages, API key, or paid service are needed.

## Option A — Download the repository ZIP

1. Open the GAIA GitHub repository in Chrome:
   https://github.com/walidwalidwalid2019oo-bit/GAIA-HEARTOFTHEWORLD
2. Tap the green **Code** button.
3. Choose **Download ZIP**.
4. Open the ZIP with your file manager and extract it.
5. Open Pydroid 3.
6. In Pydroid, open the extracted project folder and select `app.py`.
7. Tap the yellow Run button.

If Pydroid asks for storage access, allow access so it can read the extracted project.

## Option B — If the project is already cloned

1. Open the project folder in Pydroid 3.
2. Open `app.py`.
3. Tap Run.

## What to expect

The app opens a text-based GAIA command center with:
- Communicate with GAIA
- Subsystem database
- System status
- Memory Vault
- HEPHAESTUS / The Forge

Memory notes and blueprint drafts are saved in the local `data` folder after the first run.

## Important

This is the first local app prototype. The conversation router is rule-based, not a connected AI model. Do not add API keys to public GitHub files. The next development milestone is a graphical Android interface and then an optional secure AI connection.
